Tagging benchmark

Dry-run classifies every photo/video in the given date range and compares against the actual Immich tags. A summary table breaks down recall by bucket and pet; below that, only mismatches are shown as thumbnails: Missing (you tagged it, the model didn't) and Extra (the model would tag it, you didn't). Correct agreements aren't shown as thumbnails, only counted in the table.

Immich's tags in the scanned range are treated as ground truth. Before running this on a range, make sure every photo/video in it has already been manually tagged, double-checked, and corrected — any date range with un-reviewed or wrong tags will produce misleading Missing/Extra/Recall numbers, since the benchmark can only be as accurate as what it's compared against.

CLIP threshold per bucket: how confident CLIP (the tagging model) must be (0-1) before it tags a photo/video, using a separate cutoff depending on what YOLO (the detector) found. Only affects this benchmark run, not live tagging. Applies to both photos and videos; the results table still breaks those out separately.
YOLO detection confidence (0-1): controls which bucket above a photo/video falls into. Only affects this benchmark run, not live detection.
